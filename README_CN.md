> Nemo 是一个活在你手机*里面*的 AI Agent——开源、永远免费、离线可用。

## 它能做什么？

用自然语言告诉 Nemo 你想做什么。它读取屏幕、思考、然后操作——就像你自己操作一样。

```
"打开微信给张三发消息说明天开会"     → 打开微信 → 找联系人 → 输入消息 → 发送
"关闭 WiFi"                       → 打开设置 → 找到 WiFi → 点击关闭
"在淘宝搜索 iPhone 手机壳"          → 打开淘宝 → 搜索框 → 输入关键词 → 搜索
```

## 🧬 NERVE — Nemo 的独特之处

**NERVE** = **N**emo **E**volving **R**easoning via **E**xperience

你的手机 Agent 有一个生物神经系统。不是比喻——是真实的算法：

| 系统 | 生物类比 | 功能 |
|------|---------|------|
| 🛡 **免疫系统** | 白细胞 | 检测异常屏幕（崩溃、验证码）并自动恢复 |
| ⚖️ **稳态调节** | 体温调节 | 监测成功率——失败时减速，自信时加速 |
| 🧭 **熵路由** | 快思考/慢思考 | 简单任务用缓存(0ms)，复杂任务才启动模型 |
| 🐜 **蚁群算法** | 蚂蚁信息素 | 学习 App 内的最优路径，越用越熟练 |
| 🧬 **遗传进化** | 自然选择 | 策略参数随时间进化——你的 Agent 会变聪明 |

| 🌙 **昼夜节律** | 作息周期 | 早上快速执行，晚上温和操作 |

**其他 AI Agent 是脚本。Nemo 是生命体。**

## 为什么要端侧运行？

| | 云端 Agent（OpenClaw 等） | Nemo |
|---|---|---|
| **隐私** | 屏幕数据发到服务器 | 所有数据留在手机上 |
| **费用** | $0.02/步 × 100步/天 = ¥400+/月 | 永远免费 |
| **速度** | 1-3 秒/步（网络延迟） | ~100ms/步（本地推理） |
| **离线** | 必须联网 | 飞行模式也能用 |

## ⚡ 快速开始

### 1. 下载安装
从 [Releases](https://github.com/AShan0227/nemo/releases) 下载最新 APK，安装到手机。

### 2. Setup Wizard（3 步，~5 分钟）
App 会自动引导你完成：
- **Step 1:** 开启无障碍服务（一键跳转设置）
- **Step 2:** 下载 Gemma 1B 模型（529MB，自动下载，只需一次）
- **Step 3:** 试用 Demo 任务（"打开设置"）

### 3. 开始使用
输入任何自然语言任务，Nemo 搞定剩下的。

### 零门槛体验
不想设置？点 App 里的 **"Demo"** 按钮，用 Sandbox 模式体验完整的 Agent 执行流程——不需要任何权限或模型下载。

## 隐私与安全

- ✅ 所有 AI 推理在设备端完成（Gemma 1B via MediaPipe）
- ✅ 屏幕内容永远不发送到任何服务器
- ✅ 密码/PIN/CVV 字段自动过滤
- ✅ 银行卡号、身份证号自动脱敏
- ✅ 支付、授权、删除操作默认拦截
- ✅ 设置用 AES-256 加密存储
- ✅ 开源——你可以审计每一行代码
